# 📊 Global Superstore Sales Analysis

## 📌 Project Overview

**Global Superstore Sales Analysis** is a data analytics and visualization project developed using **IBM Cognos Analytics**.

The main aim of this project is to analyze sales and profit performance across different product categories, regions, products, and order dates.

The project transforms raw sales data into meaningful visualizations and interactive dashboards, helping users understand business performance and identify important sales trends.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Compare sales across different regions.
- Identify profitable product categories.
- Understand sales trends over time.
- Analyze product-wise sales distribution.
- Compare sales and profit relationships.
- Present business insights through visual dashboards.

## 🛠️ Tools & Technologies Used

- **IBM Cognos Analytics** – Dashboard creation and data visualization.
- **Microsoft Excel** – Dataset preparation and data management.

## 📁 Dataset Description

The project uses a sample Global Superstore sales dataset containing approximately 20 records.

The dataset includes the following six important columns:

| Column | Description |
|---|---|
| Order Date | Date of the order |
| Region | Geographical sales region |
| Category | Product category |
| Product Name | Name of the product |
| Sales | Sales amount |
| Profit | Profit earned |

## 📈 Dashboard Visualizations

The project includes multiple visualizations to explore different aspects of sales and profit performance.

### 1. Sales and Profit by Category
Compares sales and profit across Furniture, Office Supplies, and Technology categories.

### 2. Profit by Region
Displays the profit generated by different geographical regions.

### 3. Sales Trend Over Time
Shows how sales values change across different order dates.

### 4. Profit by Category
Compares the profit contribution of each product category.

### 5. Sales by Region
Visualizes the distribution of sales among different regions.

### 6. Profit by Order Date
Displays profit performance across order dates.

### 7. Sales by Product Category
Uses a Treemap visualization to represent sales distribution across product categories.

### 8. Sales by Region and Category
Compares category-wise sales performance across different regions using a stacked column chart.

### 9. Product Sales Distribution Analysis
Visualizes product-level sales distribution across different categories.

### 10. Sales and Profit Relationship
Uses a scatter plot to examine the relationship between sales and profit.

### 11. Daily Sales Performance
Uses a heatmap-style visualization to represent sales performance across order dates.

### 12. Category-Wise Profit Distribution
Displays the profit distribution across different product categories.

## 🔍 Project Workflow

1. Prepared the Global Superstore dataset using Microsoft Excel.
2. Imported the dataset into IBM Cognos Analytics.
3. Created a Data Module.
4. Developed dashboards using different chart types.
5. Analyzed sales and profit performance.
6. Created a detailed project report.
7. Exported the report into PDF format.

## 💡 Key Insights

The visualizations help explore:

- Differences in sales performance across regions.
- Profit contribution of individual product categories.
- Changes in sales and profit across order dates.
- Product-wise sales distribution.
- Relationships between sales and profit.
- Regional differences in category-wise sales.

*Note: Insights are based on the sample dataset used in this project.*
